# NixOS Rice

A personal NixOS configuration for a lightweight Hyprland desktop. It includes
system modules, Home Manager settings, and a small collection of application
configurations managed from one flake.

## Arch Linux

The application configs are portable to Arch Linux. The Arch bootstrap installs
the equivalent system packages and services, then links the existing configs
into `~/.config`:

```bash
./arch/install.sh
```

Run it from an Arch installation with an NVIDIA GPU and a normal user account.
It uses `pacman`, enables NetworkManager, Bluetooth, Docker, SDDM, and SSH, and
adds the user to the `docker` group. Existing config files are moved aside with
an `arch-backup` timestamp before links are created. If `paru` is installed,
the required `walker` and `elephant` AUR packages are installed as well;
otherwise install the entries in `arch/aur-packages.txt` manually. Remove
`nvidia-open` if the machine uses different graphics hardware.

## What's included

- Hyprland and desktop services
- Home Manager configuration for user `alba`
- Quickshell bar with system information
- Configurations for Hyprland, Foot, Tofi, Walker, and Fastfetch
- Modular NixOS settings under `nix_config/nixos-config-parts/`

The repository layout is:

```text
nix_config/
├── flake.nix
├── configuration.nix
├── home.nix
├── nixos-config-parts/
└── app-configs/
```

Files under `nix_config/app-configs/` are installed into `~/.config/` by Home
Manager through `xdg.configFile`.

## Requirements

- NixOS with flakes enabled
- An `x86_64-linux` system
- Git
- A working graphical session with Hyprland-compatible hardware

## Check the configuration

Run these commands from the repository root:

```bash
nix flake check ./nix_config --no-build --show-trace
nix build ./nix_config#nixosConfigurations.BonDia.config.system.build.toplevel \
  --dry-run --show-trace
```

## Install or update

Review the configuration before applying it. Then switch to the new system:

```bash
sudo nixos-rebuild switch --flake ./nix_config#BonDia
```

The `BonDia` output is the machine configuration defined in `flake.nix`.

## Adapting it to another machine

This configuration was copied from one specific NixOS installation. Before
using it elsewhere:

1. Replace `nix_config/hardware-configuration.nix` with the file generated by
   `nixos-generate-config` on the target machine.
2. Review disk UUIDs in `nix_config/nixos-config-parts/map-disks.nix`.
3. Review the username, home directory, graphics driver, boot settings, and
   enabled services.
4. Remove or change machine-specific paths in the application configs.

Do not reuse hardware configuration or disk mappings blindly.

## Notes

The screenshots may contain local network information. The configuration is a
personal rice rather than a universal hardware profile, so treat it as a
starting point and audit it before applying it to another system.
